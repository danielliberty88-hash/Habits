# Habit Tracker Bot

Telegram-бот для отслеживания привычек: ежедневные и еженедельные напоминания о прогрессе, гибкое расписание по дням недели, заморозка привычек на время перерыва и недельная визуализация выполнения.

Написан на Python с использованием ООП (три класса с чётким разделением ответственности) и библиотеки [aiogram 3.x](https://docs.aiogram.dev/).

## Возможности

- Добавление привычек с произвольной целью (`target`) и расписанием по дням недели
- Отметка выполнения через inline-кнопки
- Стрик (серия дней подряд), который автоматически обнуляется при пропуске активного дня
- Недельный отчёт — визуальная сводка по каждой привычке за последние 7 дней (✅ выполнено / ❌ пропущено / ⬬ не по расписанию)
- Заморозка привычки — временная пауза без потери стрика (например, на время болезни или отпуска)
- Редактирование расписания привычки по дням недели прямо в чате
- Удаление привычки (в том числе массовое, с подтверждением)
- Данные каждого пользователя хранятся отдельно и переживают перезапуск бота

## Команды

| Команда | Описание |
|---|---|
| `/start` | Приветствие и краткая справка |
| `/help` | Список всех команд |
| `/add <название> [цель]` | Добавить привычку. Цель необязательна (по умолчанию 1) |
| `/done` | Отметить привычку выполненной сегодня (через кнопки) |
| `/list` | Список привычек и их статус на сегодня |
| `/weekly_report` | Недельная сводка по каждой привычке |
| `/edit_days` | Изменить дни недели, в которые привычка активна |
| `/freeze` | Поставить привычку на паузу |
| `/unfreeze` | Снять привычку с паузы |
| `/del` | Удалить привычку (одну или все сразу, с подтверждением) |

## Архитектура

Проект разделён на два файла с чёткой границей ответственности:

**`models.py`** — бизнес-логика, ничего не знает про Telegram:
- `Habit` — одна привычка: название, цель, серия (streak), расписание по дням недели, история выполнений, статус заморозки
- `HabitTracker` — управляет списком привычек одного пользователя: добавление, отметка выполнения, ежедневный сброс с проверкой пропусков, недельный отчёт
- `Storage` — сохраняет и загружает привычки пользователя в JSON-файл

**`bot.py`** — вся телеграм-специфика:
- Хендлеры команд и inline-кнопок (aiogram)
- Middleware, которая перед каждым сообщением или кликом подгружает трекер нужного пользователя и синхронизирует его состояние с текущим днём
- Словарь активных трекеров в памяти (по одному на `chat_id`)

Такое разделение позволяет использовать `models.py` независимо от способа доставки сообщений — вся логика привычек не завязана на Telegram и теоретически может обслуживать любой другой интерфейс.

## Стек

- Python 3
- [aiogram 3](https://github.com/aiogram/aiogram) — асинхронный фреймворк для Telegram-ботов
- `python-dotenv` — хранение токена бота вне кода
- JSON — хранение данных (по одному файлу на пользователя)

## Установка и запуск

1. Клонируйте репозиторий и перейдите в его папку:
   ```
   git clone https://github.com/danielliberty88-hash/Habits
   cd Habits
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и получите токен.

4. Создайте файл `.env` в корне проекта со следующим содержимым:
   ```
   BOT_TOKEN=ваш_токен_от_botfather
   ```

5. Запустите бота:
   ```
   python bot.py
   ```

## Возможные улучшения

- Переход с JSON на SQLite для более надёжного хранения данных
- Напоминания по расписанию через планировщик задач (например, `apscheduler`)
- Деплой на сервер для постоянной работы бота
